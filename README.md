# Luci News 📰

[![Flutter Version](https://img.shields.io/badge/Flutter-3.32.8-blue?logo=flutter&logoColor=white)](https://flutter.dev)

[![Dart Version](https://img.shields.io/badge/Dart-3.8.1-blue?logo=dart&logoColor=white)](https://dart.dev)


**Luci News**, Flutter ile geliştirilmiş modern ve hızlı bir mobil haber uygulamasıdır. Kullanıcılar güncel haberleri takip edebilir, kategori bazlı filtreleme yapabilir ve favori haberlerini kaydedebilir.

---

## 📌 Özellikler
- 📰 **Kategori Bazlı Haberler:** Teknoloji, Spor, Sağlık, Ekonomi ve daha fazlası.  
- 🔍 **Arama:** Haber başlıkları ve içeriklerde hızlı arama.  
- ⭐ **Favoriler:** Beğendiğin haberleri favorilere ekle ve kaydet.  
- 🌐 **Gerçek Zamanlı Veriler:** REST API üzerinden güncel haberler.  
- 📱 **Responsive UI:** Hem Android hem de iOS uyumlu modern tasarım.  
- 🔒 **Firebase Entegrasyonu:** Kullanıcı kimlik doğrulama ve favori haber yönetimi.  

---

## 🛠 Teknolojiler
- **Flutter & Dart** – Mobil uygulama geliştirme  
- **REST API** – Haber verilerini çekmek için ([NewsAPI](https://newsapi.org))  
- **MobX** – State Managment  
- **Firebase** – Authentication Firestore

## ⚡ Kurulum

1. Flutter ortamını kur:  
   [Flutter Kurulum Rehberi](https://flutter.dev/docs/get-started/install)  

2. Depoyu klonla:
   ```bash
   git clone https://github.com/Furkanncm/newsapp.git
   cd newsapp

3. Bağımlılıkları yükle:
    ```bash
    flutter pub get

4. Uygulamayı çalıştır:
    ```bash
    flutter run

## 📱 Kullanım
* Uygulamayı açtıktan sonra kategoriler arasında gezinebilir ve güncel haberleri görüntüleyebilirsin.

* Haber detayına tıklayarak tam içerik ve görsellere ulaşabilirsin.

* Favorilere eklenen haberler, ayrı sekmede görüntülenir ve kaydedilir.

* Tema ve Dil değiştirerek istediğiniz gibi kullanabilirsin.
